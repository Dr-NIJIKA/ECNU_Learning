## 简介
![[Pasted image 20250608173351.png]]
每个处理器拥有私有存储（缓存）
所有处理器共享内存空间
处理器可以并行进行计算
## 临界区
共享内存系统并行编程最基本的挑战是：当多个线程需要更新共享资源时，结果可能是不可预知的
结果与更新指令执行顺序相关
- 竞争条件（Race Condition）
执行的结果取决于两个或多个事件的执行时间时，就存在竞争条件
- 临界区（Critical Section）
对共享存储区域进行更新的代码段，或会造成竞争条件的代码段。
- 原子性
- 互斥锁
## 并行性
互斥锁降低并行性
可以：定义私有变量后累积
或者：指定某个线程进行累积  吗？
## 同步
可能会出现问题：其他线程还没结束，主线程就开始计算累加结果了
- 路障（Barrier）
同步点又称为路障(barrier)，只有所有线程都抵达此路障，线程才能继续运行下去，否则会阻塞在路障处。

```C
int block_length_per_thread = n/t;   
mutex m;
shared my_sum[t];

int start = id * block_length_per_thread;   
for (i=start; i<start+block_length_per_thread; i++)  {          
     my_x = Compute_next_value(…);
     my_sum[id] += x;
}

Synchronize_cores(); // barrier for all threads

if (id == 0) { // master thread
   sum = my_sum[0];
   for (i=1; i<t; i++) sum += my_sum[t];

}
```
