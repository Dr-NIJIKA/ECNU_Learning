- **并行计算机访存模型**
均匀存储访问模型－ UMA
	–物理存储器被所有处理器均匀共享；
	–所有处理器访问任何存储字取相同的时间；
	–每台处理器可带私有高速缓存；
	–外围设备也可以一定形式共享。
非均匀存储访问模型－ NUMA
	–被共享的存储器在物理上是分布在所有的处理器中的，其所有本地存储器的集合就组成了全局地址空间；
	–处理器访问存储器的时间是不一样的；访问本地存储器LM或群内共享存储器CSM较快，而访问外地的存储器或全局共享存储器GSM较慢(此即非均匀存储访问名称的由来)；
	–每台处理器可拥有私有高速缓存，外设也可以某种形式共享。
全高速缓存访问模型－COMA
	–各处理器节点中没有存储层次结构，全部高速缓存组成了全局地址空间；
	–利用分布的高速缓存目录D进行远程高速缓存的访问;
	–COMA中的高速缓存容量一般都大于二级高速缓存容量；
	–使用COMA时，数据开始时可任意分配，因为在运行时它最终会被迁移到要用到它们的地方。
高速缓存一致性非均匀存储访问模型－CC-NUMA
	–大多数使用基于目录的高速缓存一致性协议；
	–保留SMP结构易于编程的优点，也改善常规SMP的可扩放性；
	–CC-NUMA实际上是一个分布共享存储的DSM多处理机系统；
	–它最显著的优点是程序员==无需明确地在节点上分配数据，系统的硬件和软件开始时自动在各节点分配数据==，在运行期间，高速缓存一致性硬件会自动地将数据迁移至要用到它的地方。
非远程存储访问模型－NORMA
	–所有存储器是私有的；
	–绝大数NUMA都不支持远程存储器的访问；
	–在DSM中，NORMA就消失了。

#### 并行编程模式（详见PPT）
- 主从式
- 单程序多数据流：并行运行的进程均执行相同的代码段，但处理的数据不同
- 数据流水线：将计算进程组织成一条流水线，每个进程执行特定的计算任务（相当于流水线的一个阶段）
- 分治策略
	①将输入分解成若干个规模近似相等的子问题；
	②同时递归地求解子问题；
	③归并各子问题的解成为原问题的解。

#### 并行应用编程过程PCAM
- 划分(Partitioning)
♦分解成小的任务，开拓并发性；
♦先进行数据分解(称域分解)，再进行计算功能的分解(称功能分解)；
域分解
	划分的对象是数据，可以是程序中的输入数据、中间处理数据和输出数据；
	如果一个任务需要别的任务中的数据，则会产生任务间的通信
功能分解
	划分的对象是计算（亦称为任务分解或计算划分），将计算划分为不同的任务
	研究不同任务所需的数据。如果这些数据不相交的，则划分是成功的。（更深层次）

- 通信(Communication)
♦确定诸任务间的数据交换，监测划分的合理性；
♦划分产生的各任务，一般不能完全独立执行，需要在任务间进行数据交流，从而产生了通信
	局部/全局通信(限制在一个邻域/通信是全局(All2All或者master-worker))
	结构化/非结构化通信
	静态/动态通信（通信伙伴的身份不随时间改变/可变）
	同步/异步通信（接收方和发送方协同操作/无需协同操作）

- 组合(Agglomeration)
![[Pasted image 20250607152042.png]]
♦依据任务的局部性，组合成更大的任务；

- 映射(Mapping)
将每个任务分配到处理器上，提高并行性能。
♦映射的目标：减少算法的执行时间
- 并发的任务：不同的处理器
- 任务之间存在高通信的：同一处理器
♦映射实际是一种权衡，属于NP完全问题。

#### 消息传递模型
```C
#include <mpi.h>
#include <stdio.h>

int main(int argc, char** argv) {
    MPI_Init(&argc, &argv);

    int rank, size;
    MPI_Comm_rank(MPI_COMM_WORLD, &rank);
    MPI_Comm_size(MPI_COMM_WORLD, &size);

    int local_value = rank + 1;  // 每个进程有不同的值
    int global_sum;

    // 对所有进程的local_value求和，结果存储在0号进程的global_sum中
    MPI_Reduce(&local_value, &global_sum, 1, MPI_INT, MPI_SUM, 0, MPI_COMM_WORLD);

    if (rank == 0) {
        printf("全局和: %d\n", global_sum);
    }

    MPI_Finalize();
    return 0;
}
```
